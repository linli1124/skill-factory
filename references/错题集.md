# 错题集 · 建 skill / 写校验脚本时踩过的坑

> 只记**真踩过**的，每条三段：现象 → 根因 → 对策。没踩过的不预写。

---

## 01 · 校验「SKILL.md 大小写」形同虚设

**现象**：包里只有 `skill.md`（小写），自检却报通过。

**根因**：macOS 的文件系统**默认大小写不敏感**，`os.path.exists("SKILL.md")` 对 `skill.md` 也返回 `True`。校验写成了「存在即通过」，等于没校验。

**对策**：判大小写精确，必须拿 `os.listdir()` 的真实文件名逐字比对，不能靠 `exists`。

```python
names = os.listdir(root)
if "SKILL.md" not in names:   # ✅ 逐字
    ...
```

## 02 · 批处理命令「报成功」但一个文件没动

**现象**：`for f in $LIST; do mv "$f" ...; done` 打印成功、退出码 0，实际 0 个文件被处理。

**根因**：**zsh 不做无引号变量分词**，`$LIST` 被当成**一个整串**，循环只跑一次且找不到该文件，`[ -e ]` 静默跳过。

**对策**：
- 用 `while IFS= read -r f` 逐行读（heredoc），别用空格分隔的变量
- **批处理收尾必须 `echo` 实际处理条数**——「命令成功」≠「事情做成」

## 03 · 同一条消息里并行编辑同一个文件，改动互相覆盖

**现象**：一次发 6 个 `Edit` 到同一个 HTML，全部返回成功，实测**只有 1 处生效**，其余静默丢失。

**根因**：多个编辑各自读到同一份旧内容、各自写回，后写的覆盖先写的。没有报错。

**对策**：**任何「读-改-写」同一文件的操作，必须串行**。要批量改，用一个脚本一次改完，或逐个编辑、每个改完用 `grep` 点数确认。

---

## 04 · 自检脚本把自己扫成了违规

**现象**：占位符扫描总是命中，但文件里明明没有占位符。

**根因**：脚本里的**正则字面量本身**含 `TODO`、`/Users/` 这类字样，被自己的扫描逻辑扫中了。

**对策**：扫描范围要限定目标类型（只扫 `.md/.txt/.json/.yaml`），**别把 `.py` 自己扫进去**；或在遍历时显式跳过自身路径。

---

## 05 · 文档里的相对引用悄悄断掉

**现象**：`SKILL.md` 写着「查 `错题集.md`」，但那个文件从来没建过。读者按图索骥找不到东西。

**根因**：写文档时先写指针、后建文件，中间忘了；靠人眼复核必然漏。

**对策**：把「反引号里的相对路径必须存在」做成机械检查（`selfcheck.py` 的「文档引用路径存在」一项）。**文字会忘，脚本不会。**
